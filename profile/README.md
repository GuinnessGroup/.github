<h3 align="center">"현실과 가상의 경계에서, 우리는 새로운 세계를 만듭니다."</h3>

<p align="center">기네스그룹은 마인크래프트 기반의 커뮤니티 서버 프로젝트입니다.</p>
<p align="center">현재 소드아트온라인(Sword Art Online) 테마를 중심으로 서버를 개발하고 있으며,<br>
